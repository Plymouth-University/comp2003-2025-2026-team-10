# CFD Visualisation — Final Version

**COMP2003 Team 10 | University of Plymouth | 2025–2026**

This folder contains the complete, consolidated visualisation of OpenFOAM CFD simulation data rendered in real-time 3D using Unity. It is split into two versions depending on how you want to use it.

---

## App

A pre-built Unity project with all simulation data included. Open `App/Unity Project` in Unity Hub and press Play — no configuration or pipeline runs required.

## Pipeline

The full editable version. Contains the Python processing pipeline that extracts and converts raw OpenFOAM simulation data into Unity-ready assets, along with the same Unity project. Use this version to re-run the pipeline with new simulation data or to modify the visualisation scripts.

---

Both folders contain a `README.md` with further detail.
