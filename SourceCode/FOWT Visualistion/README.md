# FOWT Visualisation

**COMP2003 Team 10 | University of Plymouth | 2025–2026**

Real-time 3D visualisation of OpenFOAM CFD simulation data rendered in Unity. Covers FOWT timesteps 30–65, originally ~220 GB of raw simulation data compressed to under 1 GB.

---

## App

Pre-built applications for Windows and Linux — just open and run, no Unity or setup required. All simulation data is included.

See `App/README.md` for details.

## Pipeline

The full processing pipeline for loading new simulation data. Edit one path, run one script, and the built app updates automatically.

See `Pipeline/README.md` for details.
