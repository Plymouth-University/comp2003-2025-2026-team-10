# Pressure Subsystem — Unity Setup

# Overview

This pressure subsystem visualises CFD pressure data as a transparent colour overlay on the water surface. Low pressure areas appear blue, high pressure areas appear red, matching the standard CFD colour convention. It animates in sync with the water surface using the same frame interpolation approach as the rest of the pipeline.
Before, the surface of the water was a simple blue.

The subsystem consists of two files:

| File                       | Purpose                                                          |
| -------------------------- | ---------------------------------------------------------------- |
| `PressureMapVisualiser.cs` | Loads pressure map PNGs at runtime and passes them to the shader |
| `PressureOverlay.shader`   | URP shader that renders the blue-to-red colour overlay           |

---

## Files to Add

| File                       | Where to put it                                            |
| -------------------------- | ---------------------------------------------------------- |
| `PressureMapVisualiser.cs` | `Assets/Scripts/`                                          |
| `PressureOverlay.shader`   | `Assets/Shaders/` (create this folder if it doesn't exist) |

---

## Setup Steps

### 1. Add the files to the project

Copy `PressureMapVisualiser.cs` into `Assets/Scripts/` and `PressureOverlay.shader` into `Assets/Shaders/`. Unity will detect and compile them automatically — wait for the progress bar in the bottom right to finish before continuing.

### 2. Add PressureMapVisualiser to the WaterSurface GameObject

In the Unity Hierarchy panel, click the **WaterSurface** GameObject. In the Inspector, scroll to the bottom and click **Add Component**. Search for `PressureMapVisualiser` and select it.

### 3. Configure the Inspector fields

With WaterSurface still selected, find the `PressureMapVisualiser` component and set:

- `Pressure Map Folder` — leave as `PressureMaps` (default)
- `Animation Speed` — match this to the `Animation Speed` value on the `WaterSurface` component
- `Scene Position` — match this to the Transform position of the WaterSurface GameObject, visible at the top of the Inspector

### 4. Add pressure map data

Create the folder `StreamingAssets/PressureMaps/` inside the Unity project's Assets folder if it doesn't exist. Place pressure map PNGs here named `pressuremap_0.png`, `pressuremap_1.png` and so on. These are generated by running the Python pipeline — see the pipeline README for details. For testing without pipeline data, two test PNGs are provided in the repo.

### 5. Press Play

The overlay will load automatically at runtime. No further Inspector setup is needed — `PressureMapVisualiser` appends the pressure material to the MeshRenderer programmatically so the existing water material is not affected.

## How It Works

`PressureMapVisualiser` reads greyscale PNG files where black represents minimum pressure and white represents maximum pressure. Each frame it interpolates between two adjacent PNGs and passes them to `PressureOverlay.shader`, which maps the pressure value at each pixel to a colour on a blue-to-red gradient and renders it transparently over the water mesh.

The overlay transparency can be adjusted by changing the `_Alpha` value in `PressureMapVisualiser.cs` line:

```csharp
material.SetFloat("_Alpha", 0.6f);
```

A value of `0` is fully invisible, `1` is fully opaque. `0.6` is the default.

## Troubleshooting

**No visual change after pressing Play**
Check the Unity Console for the error `PressureMapVisualiser: no pressure maps found`. If present, confirm the PNGs are in `StreamingAssets/PressureMaps/` and named correctly starting from `pressuremap_0.png`.

**Pink overlay instead of colour gradient**
The shader is not compiling correctly. Confirm `PressureOverlay.shader` is in `Assets/Shaders/` and that Unity has finished compiling — check the bottom right of the editor for any progress indicator.

**Overlay is visible but not animating**
Check that `Animation Speed` on `PressureMapVisualiser` is greater than 0 and that there are at least two PNG files in `StreamingAssets/PressureMaps/`.
